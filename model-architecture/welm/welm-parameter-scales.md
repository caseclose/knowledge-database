# WeLM 各规格：总参数 vs 激活参数

> 创建时间：2026-09-10 ｜ 最新更新：2026-09-10 ｜ 标签：面试、预训练

面试里问 WeLM，核心几乎总是：**总参数多大、每 token 激活多少**。它是微信 AI 的自研 LLM，产品侧跑在微信原生助手「小微」上。命名习惯与 Qwen 相同：`80B-A3B` = 总参 80B、激活 3B。

先背当前这一代（稀疏 MoE，V4）：

| 型号 | 总参数 | 激活参数 | 层数 | 备注 |
|---|---|---|---|---|
| **WeLM-80B**（V4-80B-A3B） | 80B | **3B** | 49 | 已部署小微；官方对照规格 |
| **WeLM-130B**（130B-A4.9B） | 130B | **4.9B** | 79 | 从 80B **Depth Up-Scaling**，不是从零训 |
| **WeLM-617B**（617B-A23B） | 617B | **23B** | 94 | 前沿规格；微信海报里写「在研」 |

上一代和实验档，容易和上面混：

| 型号 | 总参数 | 激活参数 | 说明 |
|---|---|---|---|
| WeLM-V3-258B-A22B | 258B | **22B** | V3，架构更传统，稀疏度明显低于 V4 |
| 消融 30.7B | 30.7B | 3B | 官方架构消融 |
| 消融 21B | 21B | 0.7B | Hidden Decoding 消融 |
| 消融 8.7B | 8.7B | 0.7B | 28 层小 MoE 消融 |
| 消融 6B | 6B | 0.6B | Hidden Decoding 小规模实验 |

2022 年第一代 WeLM 是**稠密**自回归模型，没有「激活参数」这一说：1.3B / 2.7B / 10B。网上搜到这三档，多半是旧文，别当成现在的小微基座。

> 官方统计：**总参 / 激活参都不含词向量和输出层**。80B 的 embedding 另计约 6.1B。

## 为什么激活这么小

V4 走高度稀疏 MoE：512 个路由专家 + **1 个共享专家**，每 token **top-10**。注意力是 GQA。路由用 DeepSeek 式 **loss-free 均衡** + 未归一化 sigmoid gate。

| | WeLM-80B | WeLM-617B |
|---|---|---|
| 总参 / 激活 | 80B / 3B | 617B / 23B |
| 层数 | 49（48 MoE + 1 MTP） | 94 |
| Hidden | 2048 | 4096 |
| Q / KV heads | 24 / 2 | 96 / 8 |
| Head dim | 256 | 128 |
| Experts / top-k | $512+1$ / 10 | $512+1$ / 10 |
| KV-Mirror 层数 | 16 | 30 |

激活比大致：

- V4：80B 为 $3/80=3.75\%$、617B 为 $23/617\approx 3.7\%$，和 Qwen3-Next **80B-A3B** 同一档「大总参、极小激活」。
- V3：258B-A22B 约为 $22/258\approx 8.5\%$，稀疏度更保守（激活比例更高）。

130B 没有加宽：hidden / 专家数与 80B 相同，只是把中间 **1/3 层循环复制两次**（Depth Up-Scaling，78 MoE + 1 MTP），激活从 3B 升到 4.9B。面试追问「130B 怎么来的」，答这句话即可。

## 两条容易追问的扩展

**Hidden Decoding（HD）不改主干参数。** 把每个 token 扩成 $n$ 条 stream、只监督最后一条，Transformer 激活量不变。因此：

- WeLM-HD4-80B：主干仍是 **80B / 3B 激活**（$n=4$）
- WeLM-HD4-617B：主干仍是 **617B / 23B 激活**

变的是 embedding 表（617B 上 $n=4$ 会从约 26.9B 涨到 107.4B），那是查表，不算进 MoE 算力。

**产品口径。** 微信 2026-08 海报对外点名的是 80B-A3B（已上小微）和 617B-A23B（在研）。130B、V3-258B、HD4 主要出现在技术博客 / 论文，面试里作为「系列里还有哪些档」补充。

## 总结

> **一句话：** 现在的 WeLM 是微信的稀疏 MoE：面试先背 **80B-A3B、130B-A4.9B、617B-A23B**；上一代是 **258B-A22B**；2022 年 1.3/2.7/10B 是稠密旧型号。V4 激活比约 3.7%，专家配置为 $512+1$ / top-10。
