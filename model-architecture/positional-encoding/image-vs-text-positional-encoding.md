# 图像位置编码和文本位置编码有什么区别？

Transformer 本身对 token 顺序是**置换不变**的，必须靠位置编码注入「谁在哪」。文本是 **1D 序列**，图像是 **2D 网格**，这个维度差异决定了两者位置编码的核心分歧。

## 文本：1D 顺序位置编码

| 方法 | 特点 |
|------|------|
| 正弦绝对编码（Sinusoidal） | 原始 Transformer，参数无关，**加**到 embedding 上 |
| 可学习绝对编码（Learnable APE） | 每个位置学一个向量，受最大训练长度限制、外推差 |
| **RoPE（旋转位置编码）** | 现代 LLM（LLaMA/Qwen）主流：对 Q/K 按位置**旋转**，注意力得分只依赖相对距离 (m−n)，**相对性 + 可外推** |

RoPE 的关键：用旋转而非相加，**保幅值（内容）、用角度编码位置**，内容与位置解耦更干净，长度外推更好。

## 图像：2D 空间位置编码

图像 patch 排在 H×W 网格上，只用「拉平成 1D」会丢掉原生几何（同一行/列/对角的空间关系）。

| 方法 | 特点 |
|------|------|
| ViT 原始 APE | 1D raster 顺序或 2D 可学习/正弦绝对编码；换分辨率难泛化、无显式相对关系 |
| **Axial / 2D RoPE** | 把维度切两半，沿 **x 轴、y 轴各做一次 1D RoPE**；SAM2、Qwen-Image 采用。只编码横竖关系，**缺对角方向感知** |
| **RoPE-Mixed** | 两个空间轴的频率设为**可学习**，自适应「混合」轴信号以捕捉对角/斜向 |

## 多模态：把 1D 文本和 2D/3D 视觉统一

VLM 需要在一条序列里同时放文本（1D）和图像（2D）/视频（3D）：

- **M-RoPE（Qwen2-VL）**：把视觉 token 的位置拆成 **时间 t / 高 h / 宽 w** 三组，与 1D 文本对齐。但 t-h-w 分块会造成**频率偏置**（如时间全落高频），损害长视频。
- **Interleaved-MRoPE（Qwen3-VL）**：把 t/h/w 均匀交错到全频段，缓解偏置。
- 还有 Circle-RoPE 等把图像索引投影到与文本轴正交的环上，消除跨模态伪偏置。

## 核心差异对照

| 维度 | 文本位置编码 | 图像位置编码 |
|------|-------------|-------------|
| 结构 | 1D 序列 | 2D 网格（视频 3D） |
| 主流方案 | 1D RoPE | 2D/axial RoPE、可学习 APE |
| 需编码的关系 | 前后距离 | 上下 + 左右（+ 对角） |
| 分辨率/长度变化 | 外推（RoPE 较好） | 换分辨率需插值/相对编码才好泛化 |
| 多模态统一 | — | M-RoPE / interleaved-MRoPE 融合 t-h-w 与文本 |

## 总结

> **一句话：** 文本位置编码只需处理 1D 前后顺序（现代用 1D RoPE 保相对性与外推）；图像要处理 2D 空间关系，需把 RoPE 扩到 H/W 两轴（axial/mixed 2D RoPE）或用 2D APE，多模态则用 M-RoPE / interleaved-MRoPE 把文本 1D 与视觉 2D/3D 坐标统一进同一套旋转编码。
