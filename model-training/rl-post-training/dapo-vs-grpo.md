# DAPO 和 GRPO 差在哪？四补丁让长思维链训得动

> 创建时间：2026-08-20 ｜ 最新更新：2026-08-26 ｜ 标签：面试、训练

DAPO 不是新的打分办法。它沿用 GRPO 的组内比较，专门给**长思维链**训练打了几处补丁：给新推理更大上涨空间、只练「有对有错」的题、按所有 token 公平计分、处理好超长和截断，并松开参考模型这根绳子。

Qwen2.5-32B 上 AIME 2024：朴素 GRPO 约 **30** 分，DAPO **50** 分，大约一半步数超过 DeepSeek-R1-Zero-Qwen-32B 的 47 分。[DAPO 论文](https://arxiv.org/abs/2503.14476)

配套阅读：[GRPO 在做什么](/model-training/rl-post-training/grpo-advantage-function.md)。优势公式两边一样；下面只讲 DAPO 改了什么、为什么改。

## 两边看起来很像

优势没换，仍是「这份答案比同组平均好多少」，整份回答共用一个 $\hat{A}_i$：

$$
\hat{A}_i
=
\frac{R_i - \operatorname{mean}(R_1,\ldots,R_G)}
{\operatorname{std}(R_1,\ldots,R_G)}
$$

面试里容易混：「DAPO 的 token-level」指的是 **loss 怎么平均**，不是优势改成了「知道哪一个 token 立了功」。最终答案奖励下，同一回答里的 token 仍可能共享同一个 $\hat{A}$。

GRPO 的目标（最大化 $J$，代码里常最小化 $-J$）：

$$
J_{\mathrm{GRPO}}
=
\frac{1}{G}\sum_{i=1}^{G}\frac{1}{T_i}
\sum_{t=1}^{T_i}
\min\bigl[
r_{i,t}\,\hat{A}_i,\;
\operatorname{clip}(r_{i,t},1-\varepsilon,1+\varepsilon)\,\hat{A}_i
\bigr]
-\beta\, D_{\mathrm{KL}}
$$

DAPO：

$$
J_{\mathrm{DAPO}}
=
\frac{1}{\sum_i T_i}
\sum_{i=1}^{G}\sum_{t=1}^{T_i}
\min\bigl[
r_{i,t}\,\hat{A}_i,\;
\operatorname{clip}(r_{i,t},1-\varepsilon_{\mathrm{low}},1+\varepsilon_{\mathrm{high}})\,\hat{A}_i
\bigr]
$$

并要求每组里既有对的、也有错的：

$$
0 < \#\{\text{正确答案}\} < G
$$

| 看起来一样的量 | 含义 |
|----------------|------|
| $G$ | 同一道题生成多少份答案（DAPO 论文用 $16$） |
| $T_i$ | 第 $i$ 份答案的 token 数 |
| $R_i$ / $\hat{A}_i$ | 整份奖励，以及相对同组好多少 |
| $r_{i,t}$ | 新/旧模型生成该 token 的概率比 |

公式上只动了四处：clip 不再对称、分母不再按「每份回答」平均、多了一个「有对有错」的门槛、KL 整项消失。超长处理改的是奖励 $R_i$，不另开一项 loss。

可以记成：

$$
\mathrm{DAPO}
=
\mathrm{GRPO}
+\text{非对称 clip}
+\text{动态采样}
+\text{全局 token 平均}
+\text{过长奖励处理}
-\text{固定 KL}
$$

论文消融是累加的：Naive GRPO 30 → 超长过滤 36 → Clip-Higher 38 → 软长度惩罚 41 → token-level loss 42 → 动态采样 **50**。动态采样是分数上的最大头；token-level 更多是让长度长得健康。

## 1. Clip-Higher：给新推理留上涨空间

GRPO 用对称范围，例如 $\varepsilon=0.2$ 时 $r\in[0.8, 1.2]$。

好答案要提高某个 token 的概率时，真正卡住的是**上沿** $1.2$：

- 已经很常见的 token，旧概率 $0.9$，上沿允许到 $1.08$（概率到顶，等于几乎不限制）。
- 罕见但有用的推理 token，旧概率只有 $0.01$，GRPO 最多有效提升到 $0.012$。

绝对数字看起来不大，但对「本来就很少出现的探索 token」，这会明显影响它能不能成长。策略很快变尖，一组回答几乎一个样，这就是**熵坍缩**。

DAPO 把上下沿拆开，典型 $\varepsilon_{\mathrm{low}}=0.2$、$\varepsilon_{\mathrm{high}}=0.28$，即 $[0.8, 1.28]$。只抬天花板，不把地板一起拆掉。

下沿为什么不能一起加大？加大 $\varepsilon_{\mathrm{low}}$，坏 token 能被压得更狠，容易压到 $0$，以后再也采不出来。所以叫 Clip-**Higher**：对坏行为的下降仍然谨慎，给有潜力的新推理更大上涨空间。

消融上 36→38，幅度不大，却是后面探索还能继续的前提。没有它，动态采样也只是在近乎重复的回答里挑。

clip 卡住的是概率比 $r$，不是「这份回答太好了就扔掉」。越界的 token 停止继续强化，这条 rollout 仍留在 batch 里。详见 [GRPO 文「超过 clip 会丢掉吗」](/model-training/rl-post-training/grpo-advantage-function.md)。

## 2. Dynamic Sampling：只练「既会又不会」的题

八个答案全对 $R=[1,1,1,1,1,1,1,1]$，每个都等于平均值，$\hat{A}_i\approx 0$。全错也一样。没有谁比谁好，loss 几乎没有学习信号。

DAPO 要求一组里至少一对、至少一错。不满足就丢掉或重新采，直到凑满一个「有比较价值」的 batch。

这不是公式里多出来的一项，而是决定**哪些样本有资格进 loss**：

> 只在模型既会又不会的题目上重点学习。

影响：

- 每个梯度步都有非零优势，有效样本量稳定。
- 看起来多采了一些，但同步 RL 的时间往往被最长样本绑死；论文里同一性能反而更早达到。
- 消融最大头：42→50。
- 代价：目前全错的难题、已经全对的送分题都被丢掉，暂时学不到「完全不会」或「已经会了」。模型变强后，难题会自己掉进「有对有错」的区间。

## 3. Token-Level Loss：长短回答不再平起平坐

这是两个公式最容易忽略、但很重要的区别。

GRPO 先在每份回答内部平均，再对 $G$ 份平均。每份回答最终权重基本相同。

一份 $100$ token、一份 $1000$ token，在 GRPO 里各占约一半。长回答里每个 token 的权重只有短回答的约 $1/10$。长思维链里的错误会被 $1/T_i$ 稀释；高质量的长推理也学得慢。论文观察到：不改这一层时，熵和长度会病态往上飙。

DAPO 改成把组里所有有效 token 放到一起平均：

$$
\frac{1}{\sum_i T_i}\sum_i\sum_t \ell_{i,t}
$$

每个 token 权重相同。$1000$ token 的回答整体贡献约是 $100$ token 回答的十倍。同一种生成模式，不论出现在短句还是长句，被加强或被压的力度一样。

请务必分清：

> Token-Level Loss 是**按 token 聚合 loss**，并不等于能判断是哪一个 token 导致答案正确。最终答案奖励下，同一回答内的 token 仍可能共享同一个 advantage。

消融 41→42，分数涨得少，但训练更稳、长度增长更健康。verl / TRL 里对应 `loss_agg_mode=token-mean`，GRPO 默认则是「先句内平均、再句间平均」。

## 4. 去掉 KL，并处理过长回答

GRPO 用 $-\beta D_{\mathrm{KL}}$ 当安全绳：别离初始参考模型太远。对话对齐时这合理。长思维链却要长出新行为（自检、回退、更长思路），分布本来就该远离起点。KL 会把这些新模式往回拽。DAPO 整项删掉，探索交给更高的 clip 上沿，别跑飞交给下沿 clip 和超长处理。

代价：没有显式的「别离 base 太远」。奖励一脏（格式 hack、长度 hack），更依赖规则奖励干净。所以它在数学、代码这类可验证任务上更顺；开放式对话仍有人保留可选 KL。

超长是另一类噪声。生成有最大长度，超长会被截断。若直接给截断样本一个惩罚分，一段**推理是对的、只是还没写完**的回答会被当成错的。模型分不清「逻辑错了」还是「写太长了」。

DAPO 两步处理，都是先改奖励 $R_i$，再经 $\hat{A}_i$ 进 policy loss：

1. **Overlong Filtering**：被硬截断的样本不进梯度。单步从 30→36，去噪很明显。
2. **Soft Overlong Punishment**：在硬截断前留一段缓冲。论文里期望最长 $L_{\max}=16384$，缓冲 $L_{\mathrm{cache}}=4096$，生成上限 $20480$。超过「正常最长」之后，按超出长度线性扣分，从 $0$ 扣到 $-1$，再叠到对错奖励上。模型收到的是「写对但偏长，扣一点」，不是「直接当全错」。

$$
R_{\mathrm{length}}(y)=
\begin{cases}
0, & \lvert y\rvert \le L_{\max}-L_{\mathrm{cache}} \\[4pt]
\dfrac{(L_{\max}-L_{\mathrm{cache}}) - \lvert y\rvert}{L_{\mathrm{cache}}}, & L_{\max}-L_{\mathrm{cache}} < \lvert y\rvert \le L_{\max} \\[8pt]
-1, & \lvert y\rvert > L_{\max}
\end{cases}
$$

长度可以长，但有软天花板，避免靠无止境重复、拖长思考骗到不可靠的训练信号。

## 对照：改动分别带来什么

| 维度 | GRPO | DAPO | 读成一句人话 |
|------|------|------|----------------|
| 优势 | 组内相对好坏，整份共用 | **相同** | 底座没换 |
| clip | 对称，如 $[0.8, 1.2]$ | $[0.8, 1.28]$ | 坏的照压，好的新推理多留一点上涨空间 |
| 哪些组进训练 | 全用，含全对/全错 | 只留有对有错 | 没有比较对象的题不练 |
| loss 怎么平均 | 每份回答权重相同 | 每个 token 权重相同 | 长思维链不再被 $1/T_i$ 摊薄 |
| 超长 | 常直接当负例 | 截断不训，偏长软扣分 | 别把「没写完」当成「写错了」 |
| KL | 有 | 无 | 允许推理方式离起点更远 |

GRPO 的直觉：

> 同一道题多做几遍，鼓励比同伴好的答案，压低比同伴差的答案；每份答案权重相同，并限制模型不要改变过快、不要离参考模型太远。

DAPO 的直觉：

> 延续组内比较，但只挑「有对有错」的有效题组；给优秀的新推理路径更大的上涨空间；按所有 token 统一计算权重；同时处理过长和截断回答。

> **一句话：** DAPO = GRPO + 非对称更高上沿 + 只练有比较的题 + 按 token 平均 + 超长整形 − KL。优势算法没换；换的是「谁能进训练、一次能改多猛、长短句谁说了算」。
