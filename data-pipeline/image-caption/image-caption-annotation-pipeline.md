# 图像 Caption 标注管线怎么做：两阶段 VLM 直标 + Rewrite 融合

> 创建时间：2026-07-14 ｜ 最新更新：2026-07-14

## 背景

训练文生图模型需要大量「图文对」数据。如何高效、高质量地为图像生成多粒度 caption，同时把画面中的文字和水印信息零遗漏地融入描述？

核心策略：**两阶段流水线**--先用大 VLM 直标基础字段，再用小模型 Rewrite 把 OCR 和水印信息融合进 caption。

## 方案：两阶段流水线

```
阶段一：VLM 多任务直标（Qwen3-VL-235B）
   ├─ 内容描述：keywords / short / medium / 文字分类
   ├─ 长描述：image_description（≤300 字）
   ├─ 风格：风格 / 色调 / 氛围 / 摄影手法 / 光影
   ├─ 文字检测：文字内容 + bbox + 11 种质量标签
   └─ 水印检测：水印内容 + bbox（归一化 0-1000）
                   │
                   ▼
阶段二：Rewrite 融合（Qwen3.5-9B）
   └─ 把 OCR 文字 + 水印信息零遗漏融入 CN/EN 的 short / medium / long caption
```

### 阶段一：VLM 直标

用 `Qwen3VL-235B` 对每张图独立产出 5 类结构化结果：

| 任务 | 输出 | 特点 |
|------|------|------|
| 内容描述 | keywords / short / medium + 文字分类(0/1/2) | 3 级粒度，`medium` 注入随机前缀增加多样性 |
| 长描述 | image_description（≤300 字） | 前景逐一列出 + 占比标注 + 空间关系 |
| 风格 | 6 个标签（一级/二级风格、色调、氛围、摄影、光影） | 确定性输出，不注入随机前缀 |
| 文字检测 | `[{text, bbox, tag}]`（最多 10 个区域） | 11 种质量标签（细小/模糊/粘连/错字/遮挡...） |
| 水印检测 | `{检测结果, 位置信息}` | 仅检测后叠加水印，排除场景内文字和 logo |

**随机前缀系统**：内容/长描述任务注入用户风格前缀（"照片中是..."、"生成一张..."），MD5 种子保证同一张图前缀可复现。空前缀权重 = 所有非空前缀权重之和（约 50% 不加前缀）。

### 阶段二：Rewrite 融合

用 `Qwen3.5-9B` 在原始 caption 基础上融合 OCR 和水印，**不是重新看图生成**，而是补写。

**OCR 分级策略**（核心设计）：

| 级别 | 条件 | 处理方式 |
|------|------|----------|
| T1（rich） | bbox 面积 ≥ 5% 图像 | 逐字转录 + 完整视觉属性（颜色/字体/位置/朝向） |
| T2（transcribe） | 可读，面积 < 5% | 逐字转录 + 简要位置 |
| T3（mention） | 模糊 或 字符密度 < 9e-5 | 仅描述存在，不臆测内容 |

**融合规则**：
- 清晰文字和水印必须逐字进入 caption，用英文双引号 `"..."` 包裹
- 引号内保持原图语言，不翻译、不转写、不改大小写
- 同一文字多次出现需每次都写，不能合并
- Long/Medium 允许按版式组织（海报/菜单/UI 按区块），Short 只做必要注入不扩写

## 关键工程决策

| 决策 | 原因 |
|------|------|
| 两阶段而非端到端 | 大 VLM 负责看图，小模型负责融合，成本和质量平衡 |
| OCR 分三级 | 避免模糊文字被硬转录产生幻觉，大面积文字给更多视觉属性 |
| 随机前缀 + MD5 种子 | 训练数据需要多样化的 prompt 风格，但同一图需可复现 |
| 水印检测用 system/user 消息分割 | 利用 vLLM Prefix Caching，长 prompt 缓存复用 |
| `enable_thinking: False` | 所有任务关闭思维链，提速 |
| 哨兵值错误处理 | 不崩溃，写 `__SKIPPED__` / `__ERROR__`，后续可过滤排查 |
| JSONL 断点续传 | 按 id 去重，流式追加，崩溃只丢当前批次 |

## 总结

| 要点 | 说明 |
|------|------|
| 两阶段 | 235B VLM 直标 -> 9B 模型 Rewrite 融合 |
| 零遗漏 | OCR 文字和水印逐字进 caption，双引号包裹 |
| 分级处理 | T1 详描 / T2 转录 / T3 仅提及，避免幻觉 |
| 中英双语 | 每个粒度同时产出 CN/EN 版本 |
| 工程鲁棒 | 断点续传 + 哨兵值 + 多服务器负载均衡 |

> **一句话：** 大 VLM 多任务直标 5 类结构化字段，小模型按 OCR 分级策略把画面文字和水印零遗漏融合进多粒度 caption，哨兵值 + 断点续传保证大规模标注鲁棒性。
