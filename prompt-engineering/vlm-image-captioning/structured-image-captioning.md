# 如何让纯文本大模型"看懂"图片：结构化 Caption Prompt

> 创建时间：2026-07-13 ｜ 最新更新：2026-07-14

## 背景

纯文本大模型（GLM、Llama 等）无法接收图像。常见做法是用多模态模型（VLM）先生成文字描述（Caption），再传给文本模型。

但常规 Caption 存在三个致命缺陷：

1. **OCR 遗漏**：忽略代码块、微小文字、水印、按钮文本，技术文档截图失去核心价值。
2. **视觉细节丢失**：不描述红框、箭头、高亮色块、界面布局，文本模型无法理解"重点在哪里"。
3. **主观幻觉**：模型"看图编故事"，添加图片中不存在的内容，误导下游任务。

## 解决方案

### 核心思路

用结构化思维链（CoT）强制 VLM 按固定框架输出：

1. **先搭骨架**：全局布局概览
2. **再填血肉**：按区域做"视觉特征 + 完整 OCR"交织描述
3. **最后点睛**：专门提取视觉强调（红框、高亮）
4. **绝对约束**：强制客观中立，杜绝幻觉

### Prompt 模板

可直接作为 System Prompt 或 User Prompt 发送给 VLM（Qwen2.5-VL、GPT-4o、Claude 3.5 Sonnet）：

```text
请为这张图片生成一份绝对客观的结构化描述。这份描述将输入给一个看不见图片的纯文本 AI，因此必须确保所有文字和视觉细节都被记录。

原则：
1. 只描述客观事实，不添加主观评价或编造不存在的内容。
2. 所有文字（包括微小文字、代码、水印）和视觉元素（颜色、布局、图标、标注框）都必须记录。
3. 颜色必须详细描述，颜色相近时用十六进制色值标注（如 #2e38a6），避免"深蓝""浅蓝"这类模糊表述。
4. 严格按照以下结构输出。

---

#### 1. 全局概览
- **图片类型**：（网页截图 / UI 界面 / 数据图表 / 实景照片等）
- **核心主题**：（一句话概括图片展示的主要内容）
- **整体布局**：（描述画面的空间划分）

#### 2. 详细内容拆解（按从上到下、从左到右的阅读顺序）
将画面划分为几个逻辑区域，逐个描述：
- **[区域名称]**：
  - **视觉特征**：（背景色、边框、图标、选中高亮色等）
  - **完整文字转录**：（逐字提取该区域所有文字。代码用 Markdown 代码块保留，公式描述其结构）

#### 3. 视觉强调与特殊标注
- **颜色高亮**：（如 "pkill -f 使用了红色字体和浅灰色背景"）
- **标注框/箭头**：（如 "画面右侧有两个红色矩形框，圈住了代码块右上角的 bash 标签"）
- **图标与 Logo**：（形状、颜色、位置）

#### 4. 边缘信息与元数据
- **水印/页眉页脚**：（画面边缘的微小文字、Logo 或水印）
- **其他细节**：（滚动条位置、鼠标光标、界面状态等，如有）

---
输出前自查：是否遗漏了任何文字或视觉细节？是否保持了客观？
```

### 下游文本模型的输入格式

将 VLM 输出的完整描述包裹后传给纯文本模型：

```text
以下是某张图片的详细结构化描述。请基于此描述回答我的问题：

[粘贴 VLM 的输出]

我的问题是：[用户的问题]
```

### 精简版 Prompt（快速截图描述）

日常截图快速沟通时，用这个短版本即可：

```text
请客观描述这张图片，按以下格式输出：

1. 图片类型和主题：这是什么类型的图片，展示了什么
2. 布局：画面的空间划分（左右分栏、居中、全屏等）
3. 完整文字：逐字提取所有可见文字，包括标题、按钮、菜单、代码块内容
4. 视觉强调：红框、高亮、箭头、颜色标记等用于引导视线的元素。颜色必须详细描述，相近时用十六进制色值标注（如 #2e38a6）

只描述看到的客观事实，不要编造或推测。
```

> 完整版适合技术文档截图、UI 设计稿等需要无损还原的场景；精简版适合日常截图快速沟通。

### 配置建议

| 项目 | 推荐值 | 说明 |
|------|--------|------|
| VLM（商业） | GPT-4o / Claude 3.5 Sonnet | 细节还原、OCR 极佳 |
| VLM（开源） | Qwen2.5-VL-72B / InternVL2 | 中文 OCR 开源最强 |
| Temperature | 0.1 ~ 0.3 | 低温度抑制"创造力"，保证客观 |
| Top_P | ~0.8 | 配合低温度使用 |

## 总结

| 方式 | 效果 |
|------|------|
| 常规 Caption | "技术博客截图，讲了 pkill 和 fuser，有代码和红框" - 信息丢失严重 |
| 结构化 Caption | "右侧正文区含深色代码块 `pkill -f python`，两个红色矩形框圈住 bash 标签" - 文本模型可精确理解 |

> **一句话：** 用结构化 CoT Prompt 强制 VLM 按"全局布局 -> 区域交织 -> 视觉强调"三步输出，再喂给纯文本模型，即可实现图像信息的无损传递。
